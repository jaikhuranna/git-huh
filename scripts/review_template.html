git-huh? · 2.0.1 · board rebuild

Ten pins,
ten screens.

The app has been rebuilt around the “nothing github” board. Every screen is one pin, rendered with live GitHub data. The Nothing design language — the dot-matrix face, the paper grey, the brand red — is gone from the app entirely. It survives in exactly one place: the Material You background of the first home-screen widget, resolved through the nothing-mtui token map, which is what that package is for.

What changed, and why

The 2.0 build set every screen in DotGothic16 on a grey paper canvas with a red question mark in the wordmark. That is the Nothing OS costume, so no matter which pin a screen was based on, every screen read as Nothing. The fix was not a palette tweak — it was replacing the voice.

  • Type. One dot-matrix face became three real voices: Instrument Serif for display (pin 04's “Hey,”), Inter for headings, body and pin 07's ultra-thin numeral, and IBM Plex Mono for labels and data (pin 03's typewriter index, pin 08's ~names, pin 09's caption).
  • Colour. The single brand red is gone. In its place are six categorical brights taken from pins 04, 06 and 09, used to distinguish categories — never as an accent for its own sake. The question mark in the wordmark is ink.
  • Texture. Dots were the app's only device. Now each screen borrows its own pin's: crosses on hey, ribbons on flow, stacked squares on poster, arcs on orbit, filing rules on index. Dots appear only where the source pin is built from them.
  • Icon. The launcher mark was a dot-matrix glyph. It is now the board's sigil — the same quarter-circle / dot-pair / dome / disc the card widget draws.
  • Navigation. Ten anonymous dots became a named rail, so you can see where you are and jump directly to a screen.

Two widgets

Both ship in this build and can be placed side by side.

  • git-huh? — the Material You one. Its background comes from the nothing-mtui token map: widgetBg is neutral1/50 in light and neutral1/900 in dark. The previous build called nothingWidgetColors(null, 'dark') in JavaScript, and passing null means the package hands back its static fallback — a flat #1b1b1b that never tracks the wallpaper. Those tones are Android system colours, so they can only be resolved natively. The widget now reads android.R.color.system_neutral1_50/_900 on Android 12 and up and falls back to the package's static hex below that. This is the only place Nothing red (widgetFood) appears in the project.
  • git-huh? card — the board one, from pin 08. A black card with a sigil generated from your login, your handle in IBM Plex Mono, and a halftone field of the year. No Material You, no red — it looks the same on every phone, because it is a printed card.

Data coverage

Everything the GraphQL API usefully returns now lands on a screen, rather than being collapsed into a handful of counters.

  • Profile — login, name, bio, followers, following, repo count, first active year.
  • Calendar — 365 days of per-day counts, plus weekly and monthly rollups.
  • History — every year in contributionYears, with monthly shape and a before/after-today split.
  • Breakdown — commits, pull requests, issues and reviews, then per-repository.
  • Repositories — name, description, stars, forks, visibility, last push, primary language and full language byte shares.
  • Pull requests — number, title, repo, age, draft state and URL.
  • Derived — current and longest streak (with its exact date range), best day, active days, average per day, busiest weekday, velocity and consistency.
