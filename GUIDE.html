/01

Two live loops

The app hot-reloads. The widget does not — RemoteViews render inside the launcher, not your app process. Know which one you're touching.

App UI loop (seconds). npm start in git-huh/, scan the QR with Expo Go from the Play Store. Same Wi-Fi. Every save lands on your phone in under a second. Type demo as the token — full app, fake data, zero network.
Widget loop (~20s). Phone on USB, debugging on:
cd git-huh/android
ANDROID_HOME=/tmp/opencode/android-sdk ./gradlew installRelease

Incremental after the first build. Then re-add the widget on the home screen (or wait for the 30-minute recompose) to see your change.

Desktop preview: npm start -- --web gives you a browser tab with the same hot reload. SecureStore falls back to memory there — demo mode is the intended path on web.
/02

Map of the codebase

app/index.tsx

The shell. Token gate → header → tab switch (~home / ~dots / ~prs) → TabBar. Owns sync + disconnect.

src/screens/HomeView.tsx

Insights home: red circles motif, count-up total, stat card row, glyph card.

src/screens/DotsView.tsx

The dot field card + legend + the stats mosaic (streaks, best day, busiest day).

src/screens/PrsView.tsx

Filter pills + PR date-cards. Left block number + status chip; tones cycle, third card inverts.

src/components/DotMatrix.tsx

The contribution field. Cell math, size-carried intensity, stagger entrance. Shared look, app-side.

src/theme/index.ts

All tokens, sourced from nothing-mtui. Change color/scale here first — never hardcode hex in components.

src/lib/github.ts · prs.ts

GraphQL calendar + aliased lifetime commits + REST PR search. Zod-validated at the edge.

src/lib/contributions.ts

Pure transforms: calendar → WidgetModel, quartile levels, insights. Testable, no React.

src/lib/demo.ts

Seeded fake data. The literal token "demo" routes here — layout sandbox.

android/.../widget/GitHuhWidget.kt

The real home-screen widget (Glance). Scaffold shell, glyph, hero number, native DotMatrix.

widget/WidgetState.kt · WidgetBridgeModule.kt

Payload store (SharedPreferences) + the JS→native bridge that triggers recompose.

widget/DotTextRenderer.kt · GlyphRenderer.kt

RemoteViews can't load fonts — text and glyphs are painted to bitmaps here.

/03

Rules of the grid

The whole look hangs on four decisions. Break them and it stops reading as the reference cards.

canvas #000000 card #101010 elevated #1c1c1c ink #f2f2f2 food #d71921
Every cell shows a dot. Level 0 is a small visible seed (25% size, 35% alpha), not a hole. The field is a dotted surface, sparse days included.
Size carries intensity. Levels grow 25 → 45 → 65 → 85 → 100%. Alpha only supports the story. Tune both in theme/index.ts (dotScale, dotAlpha).
Peaks square off. Level 4 renders as a 2px-radius square, like the reference cards. Everything else is a circle.
Red is rationed. One accent: today's cell, the wordmark "?", the active streak. If you're reaching for red twice in a screen, delete one.

Mirrored constants live in GitHuhWidget.kt (dotScales/dotAlphas) — the widget can't import TS, so change both when you change one.

/04

How data reaches the widget

App fetches calendar + stats + PRs (GitHub). Model is built pure: toWidgetModel().
App pushes a JSON snapshot through WidgetBridge.sync() → Kotlin writes SharedPreferences → GitHuhWidget().updateAll() recomposes every placed widget.
Widget renders only what it's given. No network, no token, no JS. Re-renders on app open + system 30-minute tick.

New widget field? Add it to the payload in src/lib/widgetBridge.ts, parse it in WidgetState.kt (use optInt for old-payload tolerance), render it in GitHuhWidget.kt.

/05

Ship ritual

# 1. gates
npx tsc --noEmit && npx expo lint

# 2. bump (versionCode + versionName) in android/app/build.gradle + app.json

# 3. build arm64
cd android && ANDROID_HOME=/tmp/opencode/android-sdk ./gradlew assembleRelease

# 4. release
gh release upload dev app/build/outputs/apk/release/app-arm64-v8a-release.apk --clobber
git add -A && git commit -m "..." && git push

Node 18 is too old for Expo CLI here — the local Node 20 lives at /tmp/opencode/node20/bin (prepend to PATH).
